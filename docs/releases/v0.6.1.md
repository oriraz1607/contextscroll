# ContextScroll v0.6.1

Fixes an invisible autoscroll cursor in GNOME when ContextScroll is installed
from an RPM. The normal pointer could disappear during scrolling because the
replacement cursor SVGs were installed in an `icons/` subdirectory while the
extension loaded them from its root directory.

Both the release and COPR RPM specs now install `autoscroll-cursor.svg` and
`autoscroll-direction.svg` directly in
`/usr/share/gnome-shell/extensions/contextscroll-pointer@contextscroll/`, matching
the existing tarball installer and extension code.

Regression checks cover both cursor paths, the other extension runtime files,
installer layout/content parity, and the absence of the obsolete `icons/`
directory for x86_64 and aarch64. CI and release validation run these checks.

The fixed package was tested with Adwaita in an isolated GNOME Shell 50.5
headless compositor: neutral and directional cursors, cursor movement,
direction awareness disabled, and restoration of the normal pointer all
passed. Bluefin/rpm-ostree installation and physical middle-click scrolling
were not tested end to end.

Downloads include RPMs and portable bundles for x86_64 and aarch64, checksums,
an SPDX SBOM, and build-provenance attestations.
